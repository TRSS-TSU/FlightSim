Step 1

Establish the local Git repository

The GitHub repository contains the Unity project files. The large map images are intentionally downloaded separately.

1

Install the tools

Install Git, Unity Hub, and Unity Editor 6000.3.3f1. The editor version is recorded by the project in ProjectSettings/ProjectVersion.txt.

2

Clone the project

Open PowerShell in the parent directory where you want the project, then run:

git clone https://github.com/TRSS-TSU/FlightSim.git
cd FlightSim

The cloned FlightSim folder is the Unity project root. It contains Assets, Packages, and ProjectSettings.

3

Pull future updates

From the project root, update a clean local checkout with:

git switch main
git pull --ff-only

Commit or stash your own work before pulling if Git reports local changes.

Step 2

Download the offline map assets

Assets/StreamingAssets is ignored by Git, so every new checkout needs both release packages extracted locally.

LIGHT

Light tactical map

Release: light-tile-map-images

Archive: mapchunks_nd_fms_tactical_gray_z14_16x16.zip

View light release Download ZIP
DARK

Dark ND map

Release: maptiles-dark

Archive: mapchunks_nd_fms_dark_nd_z14_16x16.zip

View dark release Download ZIP

Extract both ZIPs into StreamingAssets

Create Assets/StreamingAssets if it does not exist. Extract each archive so the project ends with this exact layout:

FlightSim/
└── Assets/
    └── StreamingAssets/
        ├── mapchunks_nd_fms_tactical_gray_z14_16x16/
        │   ├── manifest.json
        │   └── 14/
        └── mapchunks_nd_fms_dark_nd_z14_16x16/
            ├── manifest.json
            └── 14/

Avoid a doubled folder: .../mapchunks.../mapchunks.../manifest.json is incorrect. The manifest must sit directly inside the named map folder.

Step 3

Open and run the Unity project

  1. 1

    Add the project in Unity Hub

    Choose Add → Add project from disk, then select the cloned FlightSim folder—not its Assets subfolder.

  2. 2

    Open with 6000.3.3f1

    Allow Unity to import packages and the newly extracted map files. The first import can take longer than later launches.

  3. 3

    Open the Menu scene

    In the Project window, open Assets/Scenes/Menu.unity.

  4. 4

    Enter Play Mode

    Press Play, load Flight Scenario 01, and confirm the selected light or dark map renders without missing-chunk gaps.

Setup complete

Continue with the student procedure

The simulator should start in the Menu scene with both map themes available locally.
